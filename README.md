# Dorgesh-Kaan Agility Course Helper

Tracker for the Dorgesh-Kaan Agility Course so you don't forget what Turgall asked for.

## Features

- **Turgall highlight** — Highlights Turgall so he's easy to spot when starting a lap
- **Dialogue highlighting** — Colours the correct option in the boiler/console dialogue
- **Component highlight** — Overlays the requested component icon on top of the boiler and console
- **HUD** — Shows the requested components on screen
